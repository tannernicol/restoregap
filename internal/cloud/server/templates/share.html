Every row above comes from the latest signed bundle of one host. Each bundle's manifest is signed with an Ed25519 key that Cloud pinned the first time that host pushed. Get the public key from the host's owner by another route, compare it with the key below, then check the signature over the exact manifest bytes. The manifest lists the SHA-256 of every context file and of the ledger slice the bundle was built from; raw context files and the ledger are not published here.
